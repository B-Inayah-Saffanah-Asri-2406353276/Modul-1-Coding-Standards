## Reflection 1
Setelah mengecek kembali source code dan melakukan evaluasi, saya sudah menerapkan beberapa prinsip clean code dan secure coding. Setiap variabel, class, dan method telah diberi nama yang jelas dan sesuai dengan fungsinya. Selain itu, method dibuat singkat dan fokus pada satu fungsi agar kode lebih terstruktur. Struktur aplikasi juga sudah dipisahkan ke dalam beberapa layer, sehingga setiap bagian memiliki peran yang jelas. Dari sisi keamanan, saya telah mengimplementasikan exception handling untuk mencegah aplikasi mengalami crash ketika terjadi kesalahan yang tidak terduga. Meskipun demikian, masih terdapat beberapa aspek yang dapat ditingkatkan, seperti penambahan validasi input agar data yang diterima oleh aplikasi lebih aman.
## Reflection 2
1. Setelah menulis unit test, saya merasa lebih yakin terhadap kesesuaian fungsi kode yang dibuat karena setiap bagian sudah dites. Jumlah unit test dalam satu class bisa berbeda-beda, tapi sebaiknya mencakup berbagai skenario penting seperti kondisi normal dan kondisi error. Untuk memastikan bahwa unit test yang dibuat sudah cukup dalam memverifikasi program, salah satu hal yang dapat digunakan adalah code coverage. Code coverage menunjukkan seberapa besar bagian source code yang telah diuji. Meskipun code coverage mencapai 100%, hal tersebut tidak menjamin bahwa kode sepenuhnya bebas dari bug atau error. Hal ini terjadi karena code coverage hanya mengukur bagian kode yang dijalankan oleh test, bukan kesesuaian logika.

2. Jika saya diminta untuk membuat functional test baru untuk memverifikasi jumlah item dalam product list dengan struktur dan setup yang sama, maka dari sisi clean code hal ini bisa menurunkan kualitas kode. Pengulangan prosedur setup dan penggunaan variabel yang sama di beberapa test class menyebabkan terjadinya duplikasi kode. Kondisi ini dapat membuat proses maintenance lebih susah karena setiap perubahan harus dilakukan di banyak tempat. Untuk meningkatkan kualitas kode, bagian setup yang sama sebaiknya dipindahkan ke superclass, utility class, atau menggunakan konfigurasi bersama agar kode menjadi lebih terstruktur.
